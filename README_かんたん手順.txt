ゆか・たけ ワードゲーム PWA完成版

【やること】
1. このZIPを解凍
2. GitHubの Nazotoki-6/odaiate を開く
3. 中のファイルを全部アップロードして上書き
4. https://nazotoki-6.github.io/odaiate/ をタブレットで開く
5. ホーム画面に追加

【iPad】
Safari → 共有 → ホーム画面に追加

【Android】
Chrome → 右上メニュー → アプリをインストール / ホーム画面に追加

【オフライン確認】
一度オンラインで起動したあと、機内モードにしてホーム画面のアイコンから起動してください。

【今後更新するとき】
service-worker.js の CACHE_NAME を odaiate-pwa-v2, v3... と変更すると新しいファイルが反映されやすくなります。
