WORD HUNTER v32

更新方法
1. このZIPを解凍します。
2. GitHubの odaiate リポジトリへ、解凍したファイルをすべて上書きアップロードします。
3. 公開済みアプリを開くと、更新が検出された場合に「最新版に更新」が表示されます。
4. ボタンを押すとv32へ更新されます。

・作品名、代表作、肩書きなどの補助情報を実際のゲーム画面へ反映
・ブラウザ保存機能が利用できない場合でも起動しやすいよう安全化
